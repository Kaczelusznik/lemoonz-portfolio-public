# LeMoonz Portfolio

This repository is a **public overview of the LeMoonz Portfolio project**.

LeMoonz Portfolio is a custom portfolio and commissions website I am developing for an independent artist and animator. The project is built with **Node.js, Express, EJS, Vanilla JavaScript and CSS**, and is deployed through **Railway**.

## Why is the source code private?

The full production repository is private because this is a real project developed for a private individual.

The private repository contains client-specific content, original artwork, project assets and implementation details that are not intended for public redistribution.

Because of that, I do not publish the complete source code here.

This public repository exists only to document the project and show the technical work behind it without exposing the client's private or creative material.

## Documentation

The public technical documentation describes the project's architecture, development approach, planned production scope and roadmap.

It covers areas such as:

- Node.js / Express / EJS architecture
- frontend structure and responsive design
- accessibility
- performance
- security
- error handling
- deployment through Railway
- testing strategy
- development roadmap

The documentation intentionally excludes private biographical information and non-public material related to the artist.

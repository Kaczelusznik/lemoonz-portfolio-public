# LeMoonz

LeMoonz is a portfolio and commissions website built for an independent artist and animator.

The project went through several redesigns and a complete change in architecture before reaching its current version.

## Stack

- React
- TypeScript
- HTML / CSS
- Vite
- React Router
- Docker
- Caddy
- Railway
- Git / GitHub

## About the project

LeMoonz started as a Node.js, Express, EJS and JavaScript project.

As the website developed, it became clear that it did not actually need a backend. There were no accounts, database-driven features or server-side business logic, so keeping one would only make the project more complicated.

The final version was rebuilt around React and TypeScript, with reusable components for portfolio pages, client-side routing and a simpler frontend-only architecture.

The website currently includes:

- animation, digital, traditional and other portfolio sections
- reusable gallery components
- responsive layouts
- commission information
- contact, privacy and terms pages
- custom 404 page
- production deployment through Docker, Caddy and Railway

## Source code

The production repository is private because it contains client-specific content, artwork and assets.

This repository exists as a public overview of the project and its technical documentation.
